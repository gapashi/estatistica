# 📊 Estatística

Códigos desenvolvidos durante as aulas de **Análise de Dados com Python e IA**.

O repositório reúne exercícios e experimentos sobre conceitos de estatística, probabilidade, inferência e mineração de dados, além de uma análise exploratória de um dataset de títulos da Netflix usando pandas.

## 🛠️ Tecnologias

- **Python 3**
- **pandas**: manipulação e análise de dados (DataFrames)
- **matplotlib**: visualização de dados
- **seaborn**: gráficos estatísticos
- **CSV**: leitura e tratamento de arquivos de dados

## 📁 Conteúdo

| Arquivo | Descrição |
|---|---|
| `estatistica.py` | Conceitos e cálculos de estatística descritiva |
| `probabilidade.py` | Exercícios de probabilidade |
| `teorema_bayes.py` | Aplicação do Teorema de Bayes |
| `teste_covid.py` | Exemplo prático de probabilidade/Bayes aplicado a testes de COVID |
| `inferencia.py` | Estatística inferencial |
| `mineracao_dados.py` | Introdução à mineração de dados |
| `netflix.py` | Análise exploratória do dataset da Netflix com pandas |
| `netflix_titles.csv` | Base de dados com os títulos da Netflix, usada em `netflix.py` |

## 📚 Tópicos abordados

- Estatística descritiva
- Probabilidade
- Teorema de Bayes
- Inferência estatística
- Mineração de dados
- Análise e visualização de dados com pandas, matplotlib e seaborn
